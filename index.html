slideshow.js

A tiny lightbox for modern browsers: one script, one stylesheet, no dependencies. Click any image below to try it.

Demo

Images in links, one group spread over several elements

A whole container as one group

Setup

Include both files. Nothing else is needed, and the script can go in the <head>.

<script src="slideshow.js"></script>
<link rel="stylesheet" href="slideshow.css">

Markup

Add data-slideshow="name" to images. Everything sharing a name becomes one slideshow, in page order, even when spread across the page. The attribute can go in three places: 

<!-- on the link: the thumbnail opens the big image from href -->
<a data-slideshow="trip" href="big.jpg"><img src="small.jpg" alt="…"></a>

<!-- on the image: uses the surrounding link's href if there is one, otherwise its own src -->
<img data-slideshow="trip" src="photo.jpg" alt="…">

<!-- on a parent: every <img> inside joins the slideshow -->
<section data-slideshow="trip">
  <img src="a.jpg" alt="…">
  <a href="b-big.jpg"><img src="b.jpg" alt="…"></a>
</section>

An empty data-slideshow (no name) opens that element on its own: a single image, or just that parent's images.

Per-image attributes

AttributeWhereEffect
data-caption <a>, <img> or the data-slideshow parent Caption text. A parent's caption applies to all its images. Without it, the link's title is used, then the image's alt.
data-slideshow-src <a> or <img> URL of the full-size image, for when it isn't the link's href or the image's src.

Options

Call Slideshow.configure({ … }) after loading the script, passing only what you want to change. The script tag in this page's <head> lists every option with its default.

OptionDefaultEffect
looptrueWrap around from the last image to the first and back.
keyboardtrue← → to navigate, Home / End to jump. Esc always closes.
swipetrueSwipe left / right on touch screens.
closeOnBackdropClicktrueClick outside the image to close.
imageAreaClicktrueClick the left / right third of the image for the previous / next image.
cursorIconstrueZoom-in cursor on thumbnails, arrow cursors over the image's left / right thirds.
showUItrueShow the previous / next / close buttons and the counter.
showCaptiontrueShow captions.
showCountertrueShow the image counter.
counterFormat'{current} / {total}'Counter text.
preload1How many neighbouring images to fetch ahead, in each direction.
labelsEnglishScreen-reader labels (dialog, close, prev, next) and the error message. Pass only the ones to change.
onOpennull(item, index) => {} when the slideshow opens.
onChangenull(item, index) => {} whenever an image is shown.
onClosenull() => {} when the slideshow closes.

Callbacks receive item = { el, src, caption, alt }, where el is the clicked link or image.

Styling

Colours, sizes and timing are CSS custom properties at the top of slideshow.css. Edit them there, or override them from your own stylesheet: 

.slideshow {
  --slideshow-backdrop: rgb(0 0 0 / 0.9);
  --slideshow-color: #fff;          /* buttons, caption, counter */
  --slideshow-gap: 3rem;            /* space kept around the image */
  --slideshow-radius: 4px;          /* image corners */
  --slideshow-shadow: 0 1rem 3rem rgb(0 0 0 / 0.5);
  --slideshow-button-size: 3rem;
  --slideshow-button-bg: rgb(0 0 0 / 0.35);
  --slideshow-button-bg-hover: rgb(255 255 255 / 0.2);
  --slideshow-font: 0.95rem/1.4 system-ui, sans-serif;
  --slideshow-duration: 250ms;      /* open / close / image fade */
}

Animations are turned off automatically for visitors who prefer reduced motion. The viewer's parts have plain class names (.slideshow-image, .slideshow-caption, .slideshow-counter, .slideshow-prev, .slideshow-next, .slideshow-close) for anything further.

JavaScript API

Slideshow.open(name, index = 0)Open a slideshow by name, or pass an element instead of a name.
Slideshow.next(), Slideshow.prev()Navigate while open.
Slideshow.close()Close the slideshow.
Slideshow.configure(options)Change options; see above.
Slideshow.refresh() Images without a link are made keyboard-focusable (Enter / Space opens them) when the page loads. Call this after adding such images to the page later. Clicking works without it.
